intelligentBlondje — StreamElements widget pack
==================================================
Elke map is 1 custom widget met de tabs gescheiden:
  html.html   -> tab HTML
  css.css     -> tab CSS
  js.js       -> tab JS
  fields.json -> tab FIELDS
  data.json   -> tab DATA

IMPORTEREN
1. Ga naar streamelements.com > My Overlays > je overlay > Edit
2. Klik + (Add widget) > STATIC/CUSTOM > Custom widget
3. Open links "Settings" > "Open editor"
4. Plak per tab de inhoud van het bijbehorende bestand (Ctrl+A, Ctrl+V)
5. Klik Done — stel daarna links de velden in (titels, kleuren, logo, doelen)

FORMATEN / GROOTTES
01-starting-soon   fullscreen 1920x1080 (laat leeg scherm eronder)
02-brb             fullscreen 1920x1080
03-ending          fullscreen 1920x1080
04-intermission    fullscreen 1920x1080 (countdown via veld "minuten")
05-cam-frame       sleep over je camera; werkt op elk formaat
06-chat-box        bijv. 400x600; toont live chat in huisstijl
07-sub-goal        860x140
08-follow-goal     860x140
09-tip-goal        860x140 (prefix € instelbaar)
10-sub-counter     420x140
11-follow-counter  420x140
12-alert-box       520x120; verschijnt bij follow/sub/donatie

AUTOMATISCH
Goals, counters, "latest sub/follower" (starting soon) en alerts
lezen live StreamElements-data — geen handwerk nodig.
Emotes in de chat-box worden als tekst getoond.

Upload je logo (rond) via het logo-veld bij 01 en 04.
Stinger-overgang: OBS zelf (transition-stinger.mp4 uit de overlay-pack),
StreamElements ondersteunt geen stingers in de browser-overlay.
